# CREST CTF Writeup: EXIF Timestamps Don't Lie, But People Do

## Flag

```text
CREST{ex1f_t1m3st4mps_d0nt_l13_but_p30pl3_d0}
```

## Challenge Overview

The flag points toward a digital-forensics challenge involving EXIF metadata, timestamps, and the reliability of a person's account of when a photograph was taken.

EXIF metadata can contain information such as capture time, camera model, and camera settings. These fields can help reconstruct a timeline, but they must be interpreted carefully.

## Approach

### 1. Inspect the provided image

Start by identifying the available image files and examining their metadata. A common tool for this task is ExifTool.

```bash
exiftool -a -u -g1 image.jpg
```

This command displays a broad set of metadata fields, including duplicate and less-common tags.

### 2. Locate timestamp fields

Look for fields such as:

- `DateTimeOriginal`
- `CreateDate`
- `ModifyDate`
- `OffsetTimeOriginal`
- `FileModifyDate`

These fields do not necessarily describe the same event. For example, a file's modification time may reflect a later edit or file transfer rather than the original capture.

### 3. Compare the timeline

Compare the available timestamps with any dates, messages, filenames, or statements supplied by the challenge.

Check whether timezone information is available. A timestamp without a timezone offset may be ambiguous, and a camera's clock may have been set incorrectly.

### 4. Establish the relevant discrepancy

If the challenge provides a claimed timeline, determine whether the metadata supports or contradicts it. Preserve the original file and record the exact metadata fields used as evidence.

EXIF values are not inherently tamper-proof. They can be edited, removed, copied, or generated by software. Therefore, metadata should be treated as evidence to evaluate rather than unquestionable proof.

### 5. Recover the flag

Use the specific timestamp or metadata discrepancy identified in the challenge to obtain the expected flag.

The original image and challenge statement were not included with this request, so the precise timestamp, discrepancy, and extraction procedure cannot be independently established from the flag alone.

## Key Takeaway

Digital-forensics investigations require correlating metadata with other evidence. Timestamps can help establish a timeline, but their reliability depends on the source, timezone, and possibility of modification.
